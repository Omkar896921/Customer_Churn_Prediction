# Data dictionary

All records are synthetic sample data.

| Field | Meaning |
|---|---|
| customer_id | Synthetic customer identifier |
| tenure_months | Months as a customer |
| monthly_charges | Illustrative monthly subscription charge |
| contract_type | Month-to-month, One year or Two year |
| internet_service | Fiber optic, DSL or No |
| tech_support | Whether tech support is subscribed |
| paperless_billing | Whether paperless billing is enabled |
| payment_method | Sample payment method |
| additional_services_count | Count of additional services |
| churn | Target: 1 = churn, 0 = retained |

Synthetic patterns are intentionally simplified and are not evidence about real customers.
